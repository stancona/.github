## The chronicle (internal repositories)

Our work is organized as a federation of private repositories:

- **codex** — the master chronicle: strategic decisions (ADRs), brand and business rules — the single source of truth
- **grimoire** — the central spellbook: the application monorepo (web, apps, design system)
- **bastion** — the bastion: infrastructure, edge and deployments
- **srd** — the agentic system template used to bootstrap new projects
- **promo-video** · **portfolio** — media production and ecosystem showcases
